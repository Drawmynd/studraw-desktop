# Commissions source

## Purpose

The shared document read by every receiver and written by an administrator from the source
editor. It ships at `data/commissions.json` and is published to the public repository through git.
Receivers only read the flattened commissions; the client and type lists exist for authoring.

## Location

Default local path: `res://data/commissions.json`. Distant default:
`https://raw.githubusercontent.com/Drawmynd/studraw-desktop/main/data/commissions.json`.
Both are configurable in the sync configuration.

## Top-level fields

| Field | Type | Notes |
| --- | --- | --- |
| `version` | integer | bumped by each publication; a lower value than the cache is ignored |
| `updated_at` | integer | Unix timestamp of the last publication |
| `clients` | array | authoring list, ignored by receivers |
| `types` | array | authoring list, ignored by receivers |
| `commissions` | array | the only list receivers consume |

## Client

| Field | Type | Notes |
| --- | --- | --- |
| `id` | string | `cli-NNN`, stable |
| `name` | string | unique, case-insensitive |
| `email` | string | copied to the commission `sender` |

## Type

| Field | Type | Notes |
| --- | --- | --- |
| `id` | string | `typ-NNN`, stable |
| `name` | string | unique, case-insensitive; matches legacy type names |
| `duration_minutes` | integer | positive default duration |

Legacy defaults are illustration 2880, affiche 1440 and croquis 120 minutes.

## Commission

| Field | Type | Notes |
| --- | --- | --- |
| `id` | string | `comm-<year>-NNN`, generated by the editor |
| `title` | string | required |
| `type` | string | denormalised type name |
| `type_id` | string | authoring reference |
| `duration` | integer or null | effective minutes; the editor always writes a number, `null` only appears in hand-authored sources |
| `client` | string | denormalised client name |
| `client_id` | string | authoring reference |
| `sender` | string | mail sender, usually the client email |
| `description` | string | free description |
| `mail_request` | string | offer mail body, required |
| `mail_success` | string | success mail body |
| `mail_failure` | string | failure mail body |

## Prose

A publication replaces the three arrays wholesale and bumps the version. Because merge is by
commission id and never removes anything, deleting a commission or a client only affects
receivers that have not seen it. A legacy source without clients or types is migrated on load:
one client per distinct name, one type per distinct name, with ids assigned in memory and saved
on the next draft write.

## Out of scope

The source carries no player state (read, accepted, archived), no ordering, no gallery and no
type table consumed at runtime beyond the denormalised duration.
